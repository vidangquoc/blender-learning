# Blender Hotkeys

## Transform

| Hotkey | Chức năng |
|---|---|
| `G` | Move — Di chuyển object |
| `R` | Rotate — Xoay object |
| `S` | Scale — Phóng to / thu nhỏ object |

## Mode

| Hotkey | Chức năng |
|---|---|
| `Tab` | Chuyển Object Mode ↔ Edit Mode |

## Edit

| Hotkey | Chức năng |
|---|---|
| `Ctrl + Z` | Undo — Hoàn tác |
| `Ctrl + Shift + Z` | Redo — Làm lại |

## Animation

| Hotkey | Chức năng |
|---|---|
| `I` | Insert Keyframe |
| `Space` | Play / Pause animation |

## Viewport

| Hotkey | Chức năng |
|---|---|
| `N` | Mở / đóng Sidebar (N-Panel) |
| `T` | Mở / đóng Toolbar bên trái |

## Ghi chú

File này dùng để lưu và bổ sung các hotkey Blender trong quá trình học animation Roblox.
