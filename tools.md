# Tools

## Blender Animations Plugin for Roblox

- **Tên:** Blender Animations Plugin (Cautioned)
- **Mục đích:** Công cụ hỗ trợ workflow animation giữa Roblox Studio và Blender. Với mục tiêu hiện tại là chỉ animate và render phim trong Blender, hãy kiểm tra kỹ hướng dẫn và khả năng tương thích trước khi cài; có thể không cần dùng các tính năng gửi animation ngược về Roblox.
- **GitHub:** https://github.com/Cautioned/Blender-Animations-Plugin
