# Roblox Studio — Hotkeys & Trackpad Controls (macOS)

Ghi chú nhanh khi dùng Roblox Studio trên MacBook trackpad để quan sát rig, chỉnh scene và làm animation bằng Moon Animator 2.

> **Lưu ý:** Một số phím tắt và cử chỉ camera có thể khác theo phiên bản Studio, chế độ camera hoặc shortcut đã tùy chỉnh. Khi dùng phím điều khiển camera, hãy click vào vùng **3D Viewport** trước. Moon Animator 2 có bộ phím tắt riêng; nhiều lệnh dùng **Control (⌃)** chứ không phải **Command (⌘)** trên Mac.

## 1. Điều khiển camera trong Viewport

| Việc cần làm | Thao tác |
|---|---|
| **Xoay góc nhìn (Orbit)** | Dùng cử chỉ trackpad để xoay trong 3D Viewport. Cử chỉ chính xác có thể tùy chế độ camera. |
| Phóng to / thu nhỏ (Zoom) | Vuốt hai ngón lên hoặc xuống để cuộn. Hướng zoom có thể tùy cài đặt. |
| **Zoom chậm/chính xác hơn** | Trong **File → Beta Features → New Studio Camera Controls**, bật camera mới nếu cần. Ở chế độ này, giữ **Shift** khi thao tác di chuyển/zoom có thể làm camera di chuyển chậm hơn. Hành vi có thể khác ở camera cũ. |
| Điều chỉnh tốc độ cuộn camera | Với **New Studio Camera Controls** (Beta), giữ nút chuột phải trong khi cuộn bánh xe lên/xuống để tăng/giảm tốc độ cuộn. Trên trackpad, cách mô phỏng nút chuột phải tùy cài đặt macOS và Studio. |
| Tập trung camera vào rig/vật thể | Chọn part hoặc model trong Explorer/Viewport rồi nhấn **F**. |
| Di chuyển camera | **W / A / S / D**: tiến / trái / lùi / phải. |
| Di chuyển camera lên/xuống | **E**: lên; **Q**: xuống. |
| Di chuyển camera chậm/chính xác hơn | Giữ **Shift** khi dùng các phím di chuyển camera như **W / A / S / D / Q / E**. |
| Xoay camera quanh đối tượng đang focus | **,** và **.** xoay camera sang trái/phải quanh đối tượng đang được focus bằng **F**. |
| Zoom bằng bàn phím | **⌘ + =** để zoom gần; **⌘ + -** hoặc **O** để zoom xa. Có thể khác theo cấu hình/phím bàn phím. |
| Đưa đối tượng vào giữa mà không đổi mức zoom | Thử **Shift + F** nếu chế độ camera hiện tại hỗ trợ **Center Without Zooming**. |
| Di chuyển khung nhìn ngang/dọc (Pan) | Với chuột ngoài, giữ nút giữa và kéo. Nếu dùng trackpad, cử chỉ pan phụ thuộc chế độ camera và cài đặt. |

## 2. Moon Animator 2 — phím tắt

> Các phím dưới đây được tổng hợp từ danh sách keybind cộng đồng và hướng dẫn Moon Animator 2; một vài phím có thể khác theo phiên bản hoặc trạng thái focus. Nếu một tổ hợp không hoạt động trên Mac, thử **Control (⌃)** thay vì **Command (⌘)**, hoặc dùng menu chuột phải trong timeline.

### Tạo và chỉnh keyframe

| Việc cần làm | Phím tắt / thao tác |
|---|---|
| Thêm keyframe cho track đang chọn | **+ / =** (phím cộng hoặc dấu bằng; có thể cần phím cộng trên numpad tùy bàn phím) |
| Tạo keyframe ở vị trí ban đầu của object trên track hiện tại | **G** |
| Mở tùy chọn chỉnh keyframe đang chọn (ví dụ easing) | **7** hoặc **Numpad 7** |
| **Di chuyển một cụm keyframe đã chọn** | **Giữ Shift + kéo chuột (Shift + drag)** để kéo cả cụm keyframe đã chọn |
| Cắt keyframe đang chọn | **Control (⌃) + X** hoặc **Shift + X** |
| Sao chép keyframe đang chọn | **Control (⌃) + C** hoặc **Shift + C** |
| Dán keyframe | **Control (⌃) + V** hoặc **Shift + V** |
| Dán vào item đang chọn | **Shift + Control (⌃) + V** |
| Xóa keyframe đang chọn | **Delete** |
| Chọn tất cả track/keyframe | **Alt + F** |
| Nhóm keyframe đã chọn | **Control (⌃) + G** |
| Bỏ nhóm keyframe đã chọn | **Control (⌃) + U** |
| Bỏ nhóm tất cả keyframe | **Shift + Control (⌃) + U** |
| Tách (split) keyframe | **M** |
| Lấp/fill các frame | **Shift + K** |
| Lặp/repeat các frame | **Shift + L** |
| Kéo giãn các frame | **3** hoặc **Numpad 3** |
| Phản chiếu animation của rig | **Control (⌃) + R** |
| Bật/tắt handles | **Control (⌃) + B** |
| Undo | **Control (⌃) + Z** hoặc **Shift + Z** |
| Redo | **Shift + Control (⌃) + Z**; một số bản có thể nhận **Control (⌃) + Y** |

### Di chuyển trên timeline và xem animation

| Việc cần làm | Phím tắt |
|---|---|
| Phát / tạm dừng animation | **Space** hoặc **Numpad Enter** |
| Bật/tắt loop | **Tab** |
| Nhảy về đầu timeline | **1** hoặc **Numpad 1** |
| Lùi một frame | **4** hoặc **Numpad 4** |
| Tiến một frame | **6** hoặc **Numpad 6** |
| Đi tới keyframe trước | **J** |
| Đi tới keyframe tiếp theo | **K** |
| **Di chuyển giữa các keyframe bằng thao tác cuộn** | **Option (⌥) + cuộn trackpad / scroll** |
| Thu gọn / mở rộng track | **2** hoặc **Numpad 2** |
| Bật/tắt onion skin của object đang chọn | **B** |
| Áp dụng onion skin thành pose thật (nếu được hỗ trợ) | **N** |
| Xóa toàn bộ onion skin | **Alt + B** |
| Ẩn/hiện giao diện Moon Animator | **Control (⌃) + H** |
| Mở Animation Settings | **8** hoặc **Numpad 8** |
| Lưu animation Moon Animator | **0** hoặc **Numpad 0** |
| Lưu và đóng file animation | **/** hoặc **Numpad /** |
| Đóng file animation | **\\** (Backslash) |
| Xuất animation sang các rig đã thêm | **5** hoặc **Numpad 5** |
| Nhập animation | **Shift + I** |
| Mở menu thêm item | **9** hoặc **Numpad 9** |
| Hiện/ẩn track camera | **Control (⌃) + Space** |
| Xoay camera qua menu Moon Animator | **Shift + O** |
| Chuyển công cụ đang dùng | **R** |
| Chuyển giữa Local và Global | **Y** |
| Đưa model về vị trí ban đầu | **G** (tùy ngữ cảnh/phiên bản) |

### Mẹo sao chép pose sang frame khác

1. Chọn keyframe(s) cần sao chép trong timeline.
2. Nhấn **Control (⌃) + C** hoặc **Shift + C**.
3. Đưa playhead đến frame đích.
4. Nhấn **Control (⌃) + V** hoặc **Shift + V**.
5. Kiểm tra xem keyframe mới đã xuất hiện đúng ở frame đích chưa. Đừng chỉ di chuyển playhead khi keyframe chưa được chọn.

## 3. Lưu và mở project Roblox Studio

| Việc cần làm | Phím tắt trên Mac |
|---|---|
| Lưu project hiện tại | **⌘ + S** |
| Lưu thành file/tên khác | **⌘ + Shift + S** |
| Mở file project | **⌘ + O** |
| Tạo place mới | **⌘ + N** |
| Publish lên Roblox | **⌥ + P** |
| Publish dưới dạng project mới | **⌥ + Shift + P** |

Nếu **⌘ + Shift + S** không mở hộp thoại lưu, vào menu **File** và tìm **Save to File** hoặc **Save to File As…**. Tên mục có thể thay đổi theo phiên bản và trạng thái project. Publish lên Roblox khác với lưu một bản file cục bộ.

## 4. Chạy thử trải nghiệm

| Việc cần làm | Phím tắt |
|---|---|

## 5. Công cụ và cửa sổ hữu ích

| Việc cần làm | Cách mở |
|---|---|
| Mở Command Bar | **⌘ + 9** |
| Mở Studio Settings | **⌥ + S** |
| Mở Explorer | **Window → Explorer** (hoặc tìm trong giao diện Studio nếu menu khác phiên bản). |
| Mở Properties | **Window → Properties** (hoặc tìm nút Properties trong ribbon/tab của Studio). |
| Tùy chỉnh phím tắt | **File → Customize Shortcuts** nếu phiên bản Studio có mục này. |

## 6. Mẹo khi làm animation

- Nếu camera bị lạc, chọn rig trong **Explorer** rồi nhấn **F** để đưa camera về đối tượng.
- Nếu nhấn **F** làm camera zoom quá gần, thử **Shift + F** để căn giữa mà không đổi mức zoom (nếu được hỗ trợ).
- Nếu zoom bằng trackpad quá nhanh hoặc giật, thử **Shift** trong chế độ **New Studio Camera Controls** (Beta); nếu không có tác dụng, kiểm tra chế độ camera và **Studio Settings → Camera**.
- Khi chỉnh object, phân biệt việc chọn **Model** với chọn một **Part** con; tọa độ Position áp dụng cho đối tượng đang được chọn.
- Thực hiện cử chỉ camera trong vùng **3D Viewport**, không phải trong timeline Moon Animator 2.
- Lưu project định kỳ bằng **⌘ + S**. Nếu cần bản dự phòng riêng trên máy, dùng **⌘ + Shift + S** nếu phiên bản Studio hỗ trợ.
- Nếu shortcut Moon Animator không hoạt động, click vào timeline trước và kiểm tra focus; thử phím **Control (⌃)** và dùng menu chuột phải nếu cần.
